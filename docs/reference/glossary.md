# Glossary

This glossary lists every technical term introduced on this site, in alphabetical order. Each term links to the page where it is first explained, and each page lists its new terms in a Terminology callout at the top.

[A](#a) · [B](#b) · [C](#c) · [D](#d) · [E](#e) · [F](#f) · [G](#g) · [H](#h) · [I](#i) · [J](#j) · [L](#l) · [M](#m) · [N](#n) · [O](#o) · [P](#p) · [Q](#q) · [R](#r) · [S](#s) · [T](#t) · [U](#u) · [V](#v) · [W](#w)

## A

- **accessibility** – the usability principle that a digital solution can be used by as many people as possible, on different devices and with different abilities. ([Tutorial 3 - Layouts](../basics/03_layouts.md))
- **action** – a Qt object, called a `QAction`, that represents a command such as **Save**, and sends a `triggered` signal when the user chooses it. ([Tutorial 15 - Advanced To Do](../to_do/15_advanced.md))

## B

- **binding** – a connection inside a wrapper that makes a function or object from one language available in another. ([Introduction](../start/introduction.md))
- **blocking** – describes code that stops everything else in the program from running until it finishes, such as `sleep`. ([Tutorial 10 - Time Machine Clock](../time_machine/10_clock.md))
- **boilerplate code** – a standard block of starting code that we reuse, with little or no change, at the start of every project. ([Setup](../start/setup.md))

## C

- **camel case** – writing names with no spaces, starting each new word with a capital letter, like `windowTitle`. ([Tutorial 1 - Creating Apps](../basics/01_creating_apps.md))
- **clone** – to copy a repository from GitHub onto our computer. ([Setup](../start/setup.md))
- **commit** – a saved snapshot of our changes, with a message saying what we did. ([Setup](../start/setup.md))
- **container widget** – a widget that holds and organises other widgets, such as a group box or a tab widget. ([Tutorial 8 - Time Machine UI](../time_machine/08_ui.md))
- **controller file** – the Python file that holds our app's logic and connects the view to the data. ([Tutorial 6 - Create Calculator App](../calculator/06_create.md))
- **CSV** – short for comma-separated values, a plain-text file format where each line is a row of data and commas separate the values. ([Tutorial 16 - Contacts UI](../contacts/16_ui.md))
- **custom dialog** – a dialog box we design ourselves in Qt Designer, instead of using one of Qt's ready-made dialogs. ([Tutorial 16 - Contacts UI](../contacts/16_ui.md))

## D

- **data persistence** – keeping data after a program closes, usually by saving it to a file or database. ([Tutorial 15 - Advanced To Do](../to_do/15_advanced.md))
- **decomposition** – breaking a big problem into smaller parts that are easier to understand and solve. ([Introduction](../start/introduction.md))
- **dialog box** – a small pop-up window that shows the user a message or asks them for input. ([Tutorial 14 - Basic To Do](../to_do/14_basic.md))
- **dictionary** – a collection that stores values with names, called keys, so we can look each value up by its name. ([Tutorial 15 - Advanced To Do](../to_do/15_advanced.md))
- **dynamic UI** – a user interface whose widgets move and resize to fit the window. ([Tutorial 3 - Layouts](../basics/03_layouts.md))

## E

- **event** – something that happens which the program needs to respond to, such as a button being clicked. ([Tutorial 5 - Signals and Slots](../basics/05_signals_slots.md))
- **event loop** – the part of an event-driven program that keeps checking for events and runs the matching event handlers. ([Tutorial 10 - Time Machine Clock](../time_machine/10_clock.md))
- **event-driven programming** – a style of programming where the program keeps checking for things to happen and then responds to them. ([Tutorial 5 - Signals and Slots](../basics/05_signals_slots.md))
- **exception** – an error that happens while a program is running, such as dividing by zero. ([Tutorial 7 - Refine Calculator App](../calculator/07_refine.md))
- **exception handling** – dealing with errors while a program runs, so it can carry on or show a helpful message instead of crashing. ([Tutorial 17 - Contact App](../contacts/17_app.md))

## F

- **flag variable** – a variable that stores `True` or `False` to record whether something has happened, such as whether `=` was the last button clicked. ([Tutorial 7 - Refine Calculator App](../calculator/07_refine.md))
- **fork** – our own copy of someone else's repository on GitHub, which we are allowed to push to. ([Setup](../start/setup.md))

## G

- **geometry** – a widget's position and size, given as x, y, width and height in pixels. ([Tutorial 2 - Labels](../basics/02_labels.md))
- **Git** – the industry-standard version control system, which is free and open source. ([Setup](../start/setup.md))
- **GitHub** – a website that stores Git repositories online, syncs them with our computer and adds features for sharing and collaboration. ([Setup](../start/setup.md))
- **GitHub Desktop** – an app that lets us use Git and GitHub without typing commands. ([Setup](../start/setup.md))
- **GUI** – short for graphical user interface, a user interface made of windows, buttons, menus and other graphics that we use with a mouse, keyboard or touch. ([Introduction](../start/introduction.md))

## H

- **header row** – the first row of a CSV file, which names the columns instead of holding data. ([Tutorial 17 - Contact App](../contacts/17_app.md))

## I

- **IDE** – an Integrated Development Environment, which is an app for writing, running and fixing code. ([Setup](../start/setup.md))
- **index** – the number that gives an item's position in a sequence such as a string, starting from `0`, where `-1` means the last item. ([Tutorial 7 - Refine Calculator App](../calculator/07_refine.md))

## J

- **JSON** – short for JavaScript Object Notation, a text format for storing data as labels and values, laid out like a Python dictionary. ([Tutorial 15 - Advanced To Do](../to_do/15_advanced.md))

## L

- **layout** – a Qt widget that automatically arranges the widgets inside it, such as in a row, a column or a grid. ([Tutorial 3 - Layouts](../basics/03_layouts.md))
- **leading zero** – a `0` at the start of a whole number, such as the `0` in `09`. ([Tutorial 7 - Refine Calculator App](../calculator/07_refine.md))
- **learnability** – the usability principle that a digital solution is easy for new users to learn, because it is familiar and clearly labelled. ([Tutorial 13 - To Do UI](../to_do/13_ui.md))
- **line edit** – an input widget for one line of text. ([Tutorial 13 - To Do UI](../to_do/13_ui.md))
- **list widget** – a widget that shows a list of items the user can scroll through and click. ([Tutorial 13 - To Do UI](../to_do/13_ui.md))
- **loadUi** – a PyQt function that reads a ***.ui*** file while the app runs and builds its widgets inside our window. ([Tutorial 9 - Using loadUi](../time_machine/09_loadui.md))

## M

- **menu bar** – the bar across the top of a window that holds menus such as **File**. ([Tutorial 13 - To Do UI](../to_do/13_ui.md))
- **mock-up** – a drawing of a planned user interface that shows its layout and parts before it is built. ([Tutorial 8 - Time Machine UI](../time_machine/08_ui.md))
- **modal dialog** – a dialog that must be closed before the user can go back to the main window. ([Tutorial 17 - Contact App](../contacts/17_app.md))
- **modularisation** – organising a program into separate parts, called modules, that each do one job. ([Introduction](../start/introduction.md))
- **MVC** – short for Model-View-Controller, an architecture pattern that splits an app into the data (model), the user interface (view) and the logic that connects them (controller). ([Introduction](../start/introduction.md))

## N

- **nesting** – placing one layout inside a cell of another layout to build a more complex UI. ([Tutorial 3 - Layouts](../basics/03_layouts.md))

## O

- **object name** – the name Qt Designer gives a widget, which our code uses to find it, such as `label_display`. ([Tutorial 6 - Create Calculator App](../calculator/06_create.md))

## P

- **pixmap** – an image that Qt can display, such as a PNG file shown in a label. ([Tutorial 2 - Labels](../basics/02_labels.md))
- **placeholder** – code that does nothing, such as `pass`, used to fill a gap until we write the real code. ([Tutorial 5 - Signals and Slots](../basics/05_signals_slots.md))
- **placeholder text** – faint text shown in an empty input box that hints at what to type. ([Tutorial 13 - To Do UI](../to_do/13_ui.md))
- **property** – a setting that belongs to a widget, such as its size, text or font. ([Tutorial 1 - Creating Apps](../basics/01_creating_apps.md))
- **proximity** – the visual communication principle of placing related items close together so they are seen as a group. ([Tutorial 16 - Contacts UI](../contacts/16_ui.md))
- **push** – to send our commits from our computer to the online copy of the repository. ([Setup](../start/setup.md))
- **push button** – a widget that the user clicks to make something happen. ([Tutorial 5 - Signals and Slots](../basics/05_signals_slots.md))
- **PyQt** – a Python wrapper for Qt, so we can build Qt apps in Python instead of C++. ([Introduction](../start/introduction.md))

## Q

- **Qt** – a C++ framework for building apps with graphical user interfaces that run on many kinds of devices. ([Introduction](../start/introduction.md))
- **Qt Designer** – a drag-and-drop app for designing Qt user interfaces, which saves each design as a ***.ui*** file. ([Setup](../start/setup.md))

## R

- **repository** – a special folder, often called a repo, that stores our project files and the history of every change made to them. ([Setup](../start/setup.md))

## S

- **safety** – the usability principle that a digital solution helps users avoid serious errors and recover easily when something goes wrong. ([Tutorial 14 - Basic To Do](../to_do/14_basic.md))
- **separation of concerns** – keeping different jobs in different parts of the code, so we can change one part without breaking the others. ([Introduction](../start/introduction.md))
- **signal** – a message a Qt widget sends when an event happens to it, such as a button's `clicked` signal. ([Tutorial 5 - Signals and Slots](../basics/05_signals_slots.md))
- **size policy** – a widget setting that controls how it grows or shrinks when a layout resizes it. ([Tutorial 6 - Create Calculator App](../calculator/06_create.md))
- **slot** – a method that runs in response to a signal, so it acts as the signal's event handler. ([Tutorial 5 - Signals and Slots](../basics/05_signals_slots.md))
- **spacer** – an invisible widget that pushes other widgets apart in a layout, like a spring. ([Tutorial 4 - Complex UIs](../basics/04_complex_uis.md))
- **spin box** – an input widget for whole numbers, with up and down arrows to change the value. ([Tutorial 8 - Time Machine UI](../time_machine/08_ui.md))
- **state** – the situation a program is in at a particular moment, such as the stopwatch running or stopped. ([Tutorial 11 - Time Machine Stopwatch](../time_machine/11_stopwatch.md))
- **state machine** – a way of thinking about a program as always being in one state, with rules that decide the next state when an event happens. ([Tutorial 11 - Time Machine Stopwatch](../time_machine/11_stopwatch.md))
- **static UI** – a user interface whose widgets keep the same size and position when the window is resized. ([Tutorial 3 - Layouts](../basics/03_layouts.md))
- **string slicing** – making a new string from part of another one, such as `text[:-1]` for everything except the last character. ([Tutorial 7 - Refine Calculator App](../calculator/07_refine.md))
- **style sheet** – a set of CSS-style rules that changes how a widget looks, such as its colours, font and border. ([Tutorial 2 - Labels](../basics/02_labels.md))
- **systematic testing** – testing every combination of inputs in an organised order, so no path through the program is missed. ([Tutorial 7 - Refine Calculator App](../calculator/07_refine.md))

## T

- **tab widget** – a container widget with several pages, where the user clicks a tab to choose which page to see. ([Tutorial 8 - Time Machine UI](../time_machine/08_ui.md))
- **table widget** – a widget that shows data in a grid of rows and columns, like a spreadsheet. ([Tutorial 16 - Contacts UI](../contacts/16_ui.md))
- **test coverage** – how much of a program's possible behaviour our tests check. ([Tutorial 7 - Refine Calculator App](../calculator/07_refine.md))
- **timer** – an object that sends a signal after a set number of milliseconds, either once or again and again. ([Tutorial 10 - Time Machine Clock](../time_machine/10_clock.md))
- **traceback** – the error report Python prints when a program crashes, showing the path it took to the error with the most recent step last. ([Tutorial 7 - Refine Calculator App](../calculator/07_refine.md))
- **try block** – code inside `try` that Python runs while watching for errors, so a matching `except` can catch an error instead of the program crashing. ([Tutorial 7 - Refine Calculator App](../calculator/07_refine.md))
- **tuple** – a group of values written in round brackets that works like a list but can't be changed. ([Tutorial 14 - Basic To Do](../to_do/14_basic.md))

## U

- **unpacking** – storing each value from a tuple or list in its own variable in one line, such as `new_task, ok = ...`. ([Tutorial 14 - Basic To Do](../to_do/14_basic.md))
- **utility method** – a helper method that isn't connected to a signal, but is called by other methods to do a job, such as converting values. ([Tutorial 12 - Time Machine Timer](../time_machine/12_timer.md))

## V

- **version control** – a system that tracks changes to our files over time, so we can save versions of our work and go back to an earlier one if something breaks. ([Setup](../start/setup.md))
- **virtual environment** – a separate space for one Python project with its own Python setup and libraries, so changes in one project don't affect another. ([Setup](../start/setup.md))
- **VS Code** – short for Visual Studio Code, a professional IDE that works with many programming languages through extensions. ([Setup](../start/setup.md))

## W

- **widget** – any part of a Qt user interface, such as a window, label, button or layout. ([Tutorial 1 - Creating Apps](../basics/01_creating_apps.md))
- **wrapper** – code that lets a program written in one language use a library written in another language. ([Introduction](../start/introduction.md))
